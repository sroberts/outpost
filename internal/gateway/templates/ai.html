How apps call these

Every app is started with OUTPOST_AI_URL ({{.URL}}) and a token of its own in OUTPOST_AI_TOKEN. Use the SDK the app already has, pointed at Outpost, with the token as its API key.

  • OpenAI chat, model llm$OUTPOST_AI_URL/openai/v1
  • Anthropic messages, model llm$OUTPOST_AI_URL/anthropic
  • System 1, model system1POST $OUTPOST_AI_URL/systemone/v1/systemone

The LLM generates text. System 1 answers typed questions about an input with probabilities, in one pass.

Ollama is at {{.OllamaURL}}. Pulling and removing models stays with ollama pull and ollama rm; this page lists what Ollama has each time it loads{{if .Hosted}}, and each hosted provider's models every ten minutes{{end}}.
