Calling them from an app

Use the SDK the app already has, pointed at Outpost, with the token as its API key:

  • OpenAI chat: base URL $OUTPOST_AI_URL/openai/v1, model llm
  • Anthropic messages: base URL $OUTPOST_AI_URL/anthropic, model llm
  • System 1: POST $OUTPOST_AI_URL/systemone/v1/systemone, model system1

Ollama is at {{.OllamaURL}}. Pulling and removing models stays with ollama pull and ollama rm; this page lists what Ollama has each time it loads{{if .Hosted}}, and each hosted provider's models every ten minutes{{end}}.
