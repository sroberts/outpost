How apps call these

Endpoints

Every app is started with OUTPOST_AI_URL ({{.URL}}) and a token of its own in OUTPOST_AI_TOKEN. Use the SDK the app already has, pointed at Outpost, with the token as its API key. What each app may use, its token and what it has asked for are under its Manage menu on the apps page.

  • OpenAI chat, model llm$OUTPOST_AI_URL/openai/v1
  • Anthropic messages, model llm$OUTPOST_AI_URL/anthropic
  • System 1, model system1POST $OUTPOST_AI_URL/systemone/v1/systemone
